Un maestro nunca ve datos de otro
El metrónomo no usa API — es puramente local en el cliente (Web Audio API en Wasm, AudioTrack en Android). La Guía de Niveles también es estática, hardcodeada en commonMain igual que en el prototipo. Esto mantiene el backend simple y sin endpoints innecesarios.
