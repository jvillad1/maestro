POST /auth/refresh · Refresh token (30 días)
Al hacer login, el servidor devuelve un JWT de corta vida (1 día) y un refresh token opaco de 30 días guardado en tabla refresh_tokens. El cliente lo renueva silenciosamente antes de expirar. El maestro nunca ve un "sesión expirada" inesperado.

Deploy Infraestructura de producción
1
Backend → Railway
Ktor se empaqueta como Docker container. Railway detecta el Dockerfile, lo buildea y despliega automáticamente en cada push a main. PostgreSQL incluido en el mismo proyecto Railway.
2
Frontend Web → Vercel
El build de Kotlin/Wasm genera archivos estáticos (.wasm + .js + index.html). Vercel los sirve desde CDN global. Deploy automático en cada push.
3
Android → Google Play
APK / AAB generado desde el mismo monorepo con Gradle. Deploy manual en fase inicial — automatizable con Fastlane después.
4
iOS → App Store
Requiere Mac con Xcode para compilar el target Kotlin/Native. En fase inicial: build y submit manual desde Xcode.
