Flujo de datos

Screen → observa StateFlow del ViewModel
ViewModel → llama ApiClient (Ktor Client)
ApiClient → HTTP al Ktor backend
Backend → consulta DB con Exposed
Respuesta sube la cadena de vuelta

Token JWT

Guardado en localStorage (Web) y DataStore (Android).
Al arrancar la app: si hay token válido → ir a Dashboard. Si no → Login.
