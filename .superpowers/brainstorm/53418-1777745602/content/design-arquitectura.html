¿Por qué Kotlin/Wasm para Web?

Wasm es el futuro oficial de Compose para Web — mejor rendimiento que JS, soporte nativo de Compose, y ya es estable en CMP 1.7+. Kotlin/JS (la alternativa) quedó deprecado para UI con Compose.
